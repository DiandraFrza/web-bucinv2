setup / step by step

Database tanpa
ribet.

  1. Buat databaseDi Vercel buka project → Storage → Create Database → Upstash Redis.
  2. Tambahkan 3 variableMasuk ke Settings → Environment Variables. Isi nama variable berikut dan value dari Upstash.KV_REST_API_URLKV_REST_API_TOKENARCHIVE_ADMIN_KEY
  3. RedeploySetelah klik Save di Vercel, buka Deployments → Redeploy agar setting baru aktif.
  4. Simpan isi archiveKembali ke halaman ini, masukkan Secret admin key yang sama dengan variable `ARCHIVE_ADMIN_KEY`, lalu klik Simpan semua perubahan.
Fungsi masing-masing:
URL = alamat database. Token = kunci aplikasi ke database. Admin key = password untuk mengizinkan halaman config menyimpan data. Jangan pernah membagikan token database.
